# User Management System

## Description
This project is a simple User Management System developed using PHP and OOP concepts. It allows users to register, login, and access a dashboard.

## Features
- User Registration
- Secure Login System
- Dashboard with user information
- Logout functionality
- OOP structure (Abstract class, Interface, Trait)

## Technologies Used
- PHP
- MySQL
- HTML
